# Claude Skills Collection

> A curated collection of powerful, production-ready Claude Code skills developed by Ryan Wang. These skills transform Claude from a simple coding assistant into a comprehensive personal AI system capable of content creation, translation, productivity management, and deep OS integration.
> 
> 由 Ryan Wang 开发的强大且可通过 Claude Code 直接运行的技能合集。这些技能将 Claude 从单纯的代码助手转变为全方位的个人 AI 系统，涵盖内容创作、翻译、生产力管理及深度系统集成。

---

## 🛠 Skills Overview (技能概览)

The repository is organized into 6 core categories. To use any skill, copy the specific skill folder into your `~/.claude/skills/` directory.

### Content Creation (内容创作)
- **`writing-copilot`**: A sophisticated assistant for writing, structural editing, and stylistic refinement.
- **`youtube-to-article`**: Ingests YouTube transcripts and mathematically reconstructs them into structured, readable articles.
- **`article-translator`**: A high-fidelity translation pipeline optimized for long-form articles.

### Translation (翻译与本土化)
- **`cn-to-en-translator`**: Translates Chinese text into context-aware, native-sounding professional English.

### Productivity (生产力体系)
- **`ryan-daily-journal`**: Automates daily journal template generation and collects multi-source data for evening reflections.
- **`gtdskill`**: A deep integration of Getting Things Done (GTD) methodology into daily task processing.
- **`sync-context`**: Keeps global knowledge base context synchronized automatically.
- **`fridge`**: An inventory and recipe management assistant.

### Apple Integration (Apple 生态极深集成)
- **`reminders`**: Reads, adds, and organizes tasks directly in macOS Apple Reminders via Swift/AppleScript bridging.
- **`apple-notes`**: Brings semantic search, read, and append capabilities directly to native macOS Apple Notes.

### Document Processing (文档处理)
- **`pdf2markdown`**: A high-fidelity PDF converter that preserves layouts while extracting clean Markdown.
- **`ea-pptx`**: Enterprise Architecture PPTX processor for parsing slide structures into analyzable data.

### Wellness (健康与心理)
- **`optimism-coach`**: Uses optimistic psychology frameworks to help reframe negative daily thoughts.
- **`act-coach`**: An Acceptance and Commitment Therapy (ACT) coach focusing on cognitive defusion.
- **`green-style-guidelines`**: A specialized guide for mindful, green lifestyle practices.

---

## 🚀 Getting Started

1. Ensure you have [Claude Code](https://docs.anthropic.com/en/docs/claude-code) installed.
2. Clone this repository.
3. Choose the skills you want and copy their specific directories to `~/.claude/skills/`.
4. Run `claude` and start interacting with your new specialized skills!
