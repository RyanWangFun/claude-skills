# ACT六大核心治疗过程

ACT的六大核心治疗过程包括:接触当下、解离、接纳、以己为景、价值和承诺行动。这六个过程共同构成心理灵活性。

## 心理灵活性模型

```
         接触当下
        (此时此刻)
            |
    解离 ——— 中心 ——— 接纳
(观察念头)    |    (开放态度)
            |
       以己为景
      (全然觉知)
       /        \
    价值      承诺行动
(知道重要的) (为所当为)
```

**心理灵活性三角:**
- **开放** = 解离 + 接纳
- **活在当下** = 以己为景 + 接触当下
- **做重要的事** = 价值 + 承诺行动

**ACT缩写:**
- A = 接纳你的想法和感受并且活在当下 (Accept your thoughts and feelings, and be present)
- C = 选择价值方向 (Choose a valued direction)
- T = 采取行动 (Take action)

## 1. 接触当下 (此时此刻)

**核心定义:** 有意识地与此刻发生的一切建立连接和投入,灵活地将意识置于周围的外部世界和内心世界中。

**常见问题:**
- 陷入对过去和未来的思考
- 与周围世界失去联系
- "自动导航"模式,走走过场

**关键要点:**
- 心理的当下,而非仅仅物理的当下
- 全身心投入正在做的事情
- 觉察内在体验和外在环境

**日常语言表达:**
- "注意此时此刻"
- "全神贯注"
- "活在当下"
- "临在"

## 2. 解离 (观察你的念头)

**核心定义:** 学会"退一步",与各种念头、想象和记忆保持距离。把念头当作屋外的滚滚车流,让它们来去自由。

**常见问题 - 认知融合:**
- 陷入念头被它们牵着鼻子走
- 相信念头就是事实
- 被念头控制行为

**关键要点:**
- 退后一步观察念头,而不是与之纠缠
- 念头只是文字和图片
- 用双手轻柔地捧着它而不是紧紧抓着不放

**日常语言表达:**
- "放下"
- "退一步"
- "保持距离"
- "分开"
- "解脱"
- "看着念头飘过"

## 3. 接纳 (开放的态度)

**核心定义:** 以开放的态度为各种痛苦情感、感受、冲动和情绪腾出空间。不去与它们斗争,给它们喘息的空间,接纳它们的本来面目。

**常见问题 - 经验性回避:**
- 持续挣扎于回避、压抑不想要的体验
- 与痛苦情绪战斗
- 试图摆脱内在体验

**关键要点:**
- 打开心胸,顺其自然
- 不是喜欢或想要它们,而是为它们腾出容纳空间
- 不逃避、不战斗、不被淹没

**日常语言表达:**
- "放下挣扎"
- "与感受为伴"
- "顺其自然"
- "给它腾出空间"
- "愿意拥有它"
- "开放"

## 4. 以己为景 (全然觉知)

**核心定义:** 认识到观察性自我的存在。无论想了什么、做了什么、感受到了什么,观察性自我都能在任何时候意识到。

**两个自我:**
- **思考的自我:** 总是在思考,产生念头、信念、记忆、评判、幻想、计划
- **观察性自我:** 能够意识到所有这一切的"你",一生不变的"你"

**关键要点:**
- 身体可以改变,想法可以改变,感受可以改变,角色会发生变化
- 但能够注意和观察这变化一切的"你"始终没有改变
- 这是一个不变的"你",一生不变的"你"

**日常语言表达:**
- "观察性自我"
- "全然觉察"
- "觉知之觉知"
- "纯粹的觉察"

## 5. 价值 (知道什么是重要的)

**核心定义:** 澄清在内心深处真正重要的是什么,你想成为怎样的人,你想做些什么。价值勾勒出持续行动的方向。

**价值的关键点:**
1. **价值是方向,不是目标** - 像指南针指明方向,永远不会完成
2. **价值是此时此刻的** - 目标在将来,价值在当下每一刻
3. **价值永远不需要被证明是合理的** - 它们是自由选择的
4. **价值常常需要排序** - 不同价值可能冲突,需要优先级
5. **价值是自由选择的** - 不是"应该"或"必须",而是真心想要

**价值 vs. 其他概念:**
- 价值 ≠ 目标 (价值是方向,目标是里程碑)
- 价值 ≠ 渴望/欲望 (价值是深层选择,渴望是即时想法)
- 价值 ≠ 需要 (价值是选择,需要是生存必需)
- 价值 ≠ 感受 (价值不依赖感受,痛苦时也能践行价值)

**日常语言表达:**
- "对你重要的是什么?"
- "你想成为怎样的人?"
- "你想为什么而活?"
- "你的生命指南针指向哪里?"

## 6. 承诺行动 (为所当为)

**核心定义:** 在价值的引导下采取有效的行动。通过持续的、与价值一致的行动,让生活变得丰富、充实、有意义。

**关键要点:**
- 仅仅盯着指南针,旅程不会取得进展
- 必须在选择的方向上昂首阔步向前迈进
- 即便会带来痛苦和不适,也按照价值去生活
- "为所当为" = 按照价值去生活

**可用的行为干预:**
- 目标设定
- 暴露
- 行为激活
- 技能训练 (沟通、时间管理、自信、问题解决等)

**使用技巧的原则:**
- 目的是过上有价值的生活
- 不是为了经验性回避
- 技能服务于价值,而非控制痛苦

## 心理灵活性的本质

**定义:** 个体在当下有意识地觉察和接纳所有经历的事情,并且在价值的引导下采取行动的能力。

**简化表达:** 活在当下、开放、做重要的事的能力。

**生命力 (Vitality):**
- 不是一种感觉
- 是无论此刻感觉如何,都能意识到自己尽情地活着
- 觉察到自己处在当下
- 即使在极度悲痛时也能意识到生命的活力
- "痛并快乐着"

## 两个核心病理过程

ACT认为存在两个核心的心理过程导致了大部分的心理痛苦:

### 认知融合 (Cognitive Fusion)
- 陷入或纠缠于我们的想法
- 紧抓着念头不放
- 相信念头就是事实
- 被念头控制

**对应治疗过程:** 解离

### 经验性回避 (Experiential Avoidance)
- 持续挣扎于回避、压抑不想要的想法、感受、记忆
- 试图摆脱个人体验
- 与痛苦战斗
- 消耗巨大能量却让问题更糟

**对应治疗过程:** 接纳

**经验性回避的代价:**
- 耗尽精力和能量
- 与周围世界失去联系
- 无法做重要的事情
- 问题通常变得更糟

## 六大过程的相互关联

六大核心过程不是相互独立的,它们作为一个整体相互关联,共同代表心理灵活性:

1. **解离 + 接纳** = 开放 (对内在体验开放)
2. **以己为景 + 接触当下** = 活在当下 (临在于此刻)
3. **价值 + 承诺行动** = 做重要的事 (有价值的生活)

**整合运用原则:**
- 六个过程在实际应用中常常交织在一起
- 不需要严格按顺序进行
- 灵活选择当下最需要的过程
- 最终目标是增强整体的心理灵活性
