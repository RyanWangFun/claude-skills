# ACT核心隐喻与练习

本文档汇集ACT中最常用和最有效的隐喻、练习和干预技术。

## 核心隐喻:文件夹隐喻

**用途:** 快速概述整个ACT模型,展示认知融合、经验性回避、接纳和解离的核心概念。

**所需材料:** 一个文件夹或大本硬皮书

### 第一部分:认知融合

**步骤:**
1. 让来访者想象文件夹代表所有痛苦的想法、感受和记忆
2. 请来访者紧紧抓住文件夹,不让你拿走
3. 请来访者用文件夹遮住自己的脸,直到看不见你

**引导语:**
- "当你完全陷入自己的想法和感受时,与我谈话是什么样的?"
- "你能看到我的表情吗?能看到房间四周吗?"
- "当你完全沉浸在这些东西里,你就会错过许多,失去了与周围世界的联系"

**核心洞察:** 认知融合让我们与世界失去连接,看不见生活的其他可能性。

### 第二部分:经验性回避

**步骤:**
1. 坐在来访者旁边
2. 双方各用双手按住文件夹的一面
3. 请来访者把文件夹推开,你同时推回来
4. 保持这种推搡状态一段时间

**引导语:**
- "你讨厌这些想法和感受,所以尽可能用力将它们推开"
- "你这样做已经有好几年了,可是它们消失了吗?"
- "你可以保持一臂的距离,但是你付出的代价是什么?"
- "如果整天都是如此,你会觉得如何?" (很累)
- "当你这样做时,你能做生活中重要的事吗?" (不能)

**核心洞察:** 与痛苦体验战斗消耗巨大能量,让我们无法做重要的事,且问题通常变得更糟。

### 第三部分:接纳与解离

**步骤:**
1. 停止推搡,把文件夹轻轻放在来访者腿上
2. 双手放开,让文件夹就在那里

**引导语:**
- "现在肩膀感觉如何?" (舒服多了)
- "此时你可以无拘束地做有益的事情了"
- "你能清楚看到房间四周,能与我正常交谈"
- "注意,它还在这儿,但对你的影响小多了"

**核心洞察:** 接纳和解离释放了我们的能量,让我们能够投入生活,做重要的事。

### 第四部分:创造性无望

**引导语:**
- "你当然不想要这些痛苦,谁愿意要呢?"
- "理想情况下你想这样做(扔掉文件夹)"
- "但现实是,多年来你一直试图摆脱它们"
- "你尝试过药物、酒精、自助读物、心理治疗、回避、分散注意力..."
- "尽管付出了所有努力,它们还是不断出现,甚至比以前更糟"
- "那种对策明显没有达到你想要的效果,只是让事情变得更糟"

**核心洞察:** 控制和回避的策略是无效的,需要转向正念和接纳。

### 第五部分:正念与有价值的生活

**引导语:**
- "这就是ACT。我们将学习正念技能,更有效地处理痛苦的想法和感受"
- "以这样的方式,这些痛苦对你产生的影响要少得多"
- "与其这样(遮住脸)或这样(推搡),倒不如这样(放在腿上)"
- "这能让你融入周围环境,投入正在做的事情"
- "你可以自由地做那些能提高生活质量的事情"

**核心洞察:** 正念技术不是让痛苦消失,而是改变与痛苦的关系,从而自由地过有价值的生活。

## 解离技术

### 1. 叶子漂流练习

**用途:** 学习观察念头而不被卷入

**引导:**
想象你坐在小溪边,看着树叶在水面上漂流。每当一个念头出现时,就把它轻轻放在一片叶子上,看着它顺流而下。不要试图推开它,也不要抓住它,只是看着它飘过。

**要点:**
- 念头会不断出现,这很正常
- 不需要让它们停止
- 只需要观察它们来去

### 2. "我正在想..."前缀

**用途:** 创造与念头的距离

**方法:**
在任何念头前加上"我正在想..."

**示例:**
- "我是个失败者" → "我正在想,我是个失败者"
- "没人喜欢我" → "我正在想,没人喜欢我"
- "我做不到" → "我正在想,我做不到"

**效果:** 立即从念头的内容中退一步,看到它只是一个念头。

### 3. 感谢你的头脑

**用途:** 认识到头脑的运作模式,不被它控制

**方法:**
当痛苦念头出现时,对自己说:"谢谢你,头脑,感谢你又一次试图保护我"或"好的,头脑,我知道了,谢谢分享"

**要点:**
- 不是与头脑对抗
- 承认它在尽职尽责(即使方式无效)
- 创造一种轻松、幽默的距离感

### 4. 念头命名

**用途:** 识别重复的念头模式

**方法:**
给常见的念头模式起个名字,如"失败者故事""不够好故事""灾难预测"等。当它们出现时,只需命名:"哦,又是那个'失败者故事'"

**效果:** 从被念头控制转变为观察念头模式。

### 5. 屏幕上的字幕

**用途:** 将念头可视化为外在的文字

**方法:**
想象你的念头像电影字幕一样出现在你眼前的屏幕上。只是读着它们,看着它们出现、停留、消失。

**要点:**
- 念头变成可观察的对象
- 你是观看者,不是念头本身

## 接纳技术

### 1. 扩展练习

**用途:** 为困难情绪腾出空间

**步骤:**
1. **注意:** 闭上眼睛,注意到不舒服的感受在身体哪个部位
2. **呼吸:** 深呼吸几次,想象呼吸流经那个部位
3. **扩展:** 想象在那个感受周围创造空间,不试图改变它,只是给它更多空间
4. **允许:** 允许它就在那里,不战斗,不逃避

**引导语示例:**
"注意到焦虑在哪里...也许是胸口,也许是胃部...深呼吸,想象呼吸环绕着这个感受...为它创造更多空间...允许它存在..."

### 2. 冲浪比喻

**用途:** 接纳情绪的起伏

**引导:**
情绪就像海浪。它们会上升,达到顶峰,然后下降。你不能阻止海浪,但可以学会冲浪。不要试图推开海浪,而是随着它一起移动,保持平衡。

**要点:**
- 所有情绪都会自然消退
- 抵抗会让你被海浪打翻
- 接纳让你能随波起伏

### 3. 握紧拳头练习

**用途:** 体验放松控制的感觉

**步骤:**
1. 请来访者紧握拳头,想象拳头里握着痛苦的感受
2. 握得越来越紧,体会紧张和费力
3. 问:"如果一直这样握着,会怎样?" (很累,很痛)
4. 慢慢张开手掌,让手放松
5. 痛苦还在手掌里,但不再费力

**洞察:** 接纳不是消除痛苦,而是停止与它战斗,释放能量。

### 4. 客人比喻

**用途:** 接纳不请自来的体验

**引导:**
想象你的情绪和念头是来你家的客人。有些是受欢迎的,有些不是。但如果你不停地把不受欢迎的客人推出门外,你就得一直守在门口,无法享受派对。不如让所有客人进来,他们会自己来来去去。

**要点:**
- 你不需要喜欢所有客人
- 抵抗客人消耗你的精力
- 允许他们在那里,你才能做其他事

## 接触当下练习

### 1. 五感练习 (5-4-3-2-1)

**用途:** 快速回到当下

**步骤:**
- 说出5样你能看见的东西
- 4样你能触摸到的东西
- 3样你能听见的声音
- 2样你能闻到的气味
- 1样你能尝到的味道

**效果:** 将注意力从头脑拉回到此时此刻的感官体验。

### 2. 正念呼吸

**基础版本:**
1. 坐直,双脚着地
2. 将注意力放在呼吸上
3. 注意吸气和呼气的感觉
4. 当头脑游走时,温柔地将注意力带回呼吸
5. 持续3-5分钟

**要点:**
- 头脑走神是正常的,不是失败
- 重点是注意到走神,然后带回来
- 这本身就是在训练注意力

### 3. 正念吃葡萄干

**用途:** 深度体验当下一刻

**步骤:**
1. 拿起一颗葡萄干,仿佛第一次见到它
2. 观察它的颜色、纹理、形状
3. 感受它在手指间的触感
4. 闻它的气味
5. 慢慢放入口中,不咀嚼,感受它在舌头上
6. 慢慢咀嚼,注意味道和质地的变化
7. 慢慢吞咽,感受它滑下喉咙

**洞察:** 当我们真正临在,即使最简单的事情也充满丰富的体验。

### 4. 身体扫描

**用途:** 培养对内在体验的觉察

**引导:**
从头部开始,慢慢将注意力移动到身体每个部位:头、脸、脖子、肩膀、手臂、胸部、腹部、背部、臀部、腿、脚。注意每个部位的感觉,不试图改变,只是觉察。

**时长:** 5-20分钟

## 以己为景练习

### 1. 观察者练习

**引导语:**
"注意到此刻的你正在观察你的想法...这个正在观察的'你'和被观察的想法是不同的...想法可以改变,但这个观察者一直都在...这个观察者从童年到现在一直是同一个'你'..."

**要点:**
- 区分内容(想法、感受)和容器(观察者)
- 观察者是稳定的、不变的

### 2. 天空与天气比喻

**引导:**
你就像天空,你的想法和感受就像天气。有时是晴天,有时是暴风雨。但无论天气如何,天空始终在那里,容纳一切。暴风雨无法伤害天空。

**洞察:** 你的本质(观察者)不会被想法和感受伤害或改变。

## 价值澄清练习

### 1. 葬礼练习

**引导:**
"想象你的葬礼...你希望人们记住你什么?你希望他们说你是个怎样的人?你希望你对他们的生活产生了什么影响?"

**洞察:** 从生命终点回看,什么才是真正重要的。

### 2. 80岁的自己

**引导:**
"想象你80岁了,回顾你的一生...你希望自己做过什么?成为怎样的人?什么会让你感到骄傲?什么会让你遗憾?"

### 3. 生活领域价值卡

**核心生活领域:**
- 家庭关系
- 亲密关系
- 友谊
- 工作/事业
- 教育/学习
- 休闲/娱乐
- 心灵/成长
- 健康/身体
- 社区/公民
- 环境/自然

**方法:**
对每个领域问:"在这个领域,什么对你真正重要?你想成为怎样的人?"

### 4. 价值 vs. 目标区分

**练习:**
识别哪些是价值(持续的方向),哪些是目标(可完成的事件)

**示例:**
- "成为一个有爱心的父亲" (价值) vs. "带孩子去公园" (目标)
- "学习和成长" (价值) vs. "读完一本书" (目标)
- "活出真实的自己" (价值) vs. "说出自己的想法" (目标)

## 承诺行动练习

### 1. SMART目标设定

在价值指引下设定具体目标:
- **S**pecific (具体的)
- **M**easurable (可衡量的)
- **A**chievable (可达成的)
- **R**elevant (与价值相关的)
- **T**ime-bound (有时限的)

### 2. 障碍识别与解离/接纳

**步骤:**
1. 确定一个与价值一致的行动
2. 识别可能出现的障碍(念头、感受、情境)
3. 对每个障碍应用解离或接纳技术
4. 承诺无论障碍是否出现都采取行动

**示例:**
- 行动:给朋友打电话
- 障碍:"他可能不想听我说话"(念头)
- 解离:"我正在想他可能不想听我说话"
- 承诺:即使有这个念头,我也拨打电话

### 3. 价值行动清单

**每日练习:**
早上问自己:"今天我可以做什么来践行我的价值?"
晚上问自己:"今天我有没有按照价值生活?"

### 4. 愿意体验不适

**练习:**
在采取有价值的行动之前,完成这个句子:
"为了[价值],我愿意体验[不适的感受/念头]"

**示例:**
"为了成为一个真实的人,我愿意体验被拒绝的恐惧"
"为了学习和成长,我愿意体验不知道答案的不适"

## 整合练习:日常正念

### 正念日常活动

选择一个日常活动(刷牙、洗碗、走路、喝咖啡),每次做这个活动时:
1. 全神贯注于当下的体验
2. 注意所有的感官细节
3. 当头脑走神时,温柔地带回来
4. 将此作为价值生活的微小实践

### 呼吸空间练习 (3分钟)

**应对困难时刻的快速练习:**

1. **觉察** (1分钟):发生了什么?我有什么念头、感受、身体感觉?
2. **聚焦** (1分钟):将注意力集中在呼吸上,作为锚定
3. **扩展** (1分钟):扩展觉察到整个身体,带着接纳的态度

**用途:** 在压力情境中快速回到当下,创造空间做出有价值的选择。

## 使用原则

1. **体验优于解释** - ACT是体验性疗法,做练习比讨论理论更重要
2. **灵活运用** - 根据来访者情况选择和调整练习
3. **重复练习** - 正念技能需要持续练习才能内化
4. **连接价值** - 所有练习最终服务于有价值的生活
5. **接纳不完美** - 练习时走神或做不好都是正常的,本身就是学习机会
