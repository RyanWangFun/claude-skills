# Apple Reminders Integration

> Interacts directly with macOS Apple Reminders via Swift/AppleScript to read, add, and organize tasks naturally.
> 通过 Swift/AppleScript 直接与 macOS 的原生“提醒事项”交互，自然地读取、添加和组织任务。

## Usage
Add this directory to your `~/.claude/skills/` folder to use it with Claude Code. Supported on macOS only.
