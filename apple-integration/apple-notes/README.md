# Apple Notes Integration

> Interacts directly with macOS Apple Notes, allowing semantic search, note reading, and appending capabilities.

[中文版](#中文说明)

---

## Usage
Add this directory to your `~/.claude/skills/` folder to use it with Claude Code. Supported on macOS only.
