# fridge - 家庭冰箱库存管理

通过自然语言管理 Apple Notes 中的冰箱库存表格和餐食记录。

## 数据源

- **笔记名称**: `🧊 冰箱库存`
- **所在文件夹**: `Notes`
- **Apple Notes 脚本目录**: `/path/to/skills/apple-notes/scripts/`

## 笔记结构

笔记包含两个区域：

### 1. 库存表格区（上半部分）
三个 HTML 表格，按冰箱层级组织：
- **A层（冷藏）** - 冷藏区
- **B层（化冻区）** - 化冻/过渡区
- **C层（冷冻区）** - 冷冻区

每个表格的列：`物品 | 数量 | 备注`

### 2. 餐食记录区（下半部分）
以日期为标题的倒序列表，最新日期在最上面：
```
2025-02-06
- 午餐：番茄炒蛋
- 晚餐：饺子

2025-02-05
- 午餐：炒青菜
```

## 操作流程

**每次操作都遵循：读取 → 解析 → 修改 → 写回**

### Step 1: 读取当前笔记
```bash
SKILL_DIR="/path/to/skills/apple-notes"
osascript "$SKILL_DIR/scripts/get_note.applescript" "Notes" "冰箱库存"
```

### Step 2: 解析 HTML 内容
从返回的 JSON 中提取 `body` 字段，解析出：
- 三个表格的内容（A/B/C 层各自的物品列表）
- 餐食记录区域的内容

### Step 3: 根据用户意图修改内容
见下方四个核心操作。

### Step 4: 写回笔记
```bash
osascript "$SKILL_DIR/scripts/update_note.applescript" "Notes" "冰箱库存" "$NEW_HTML_CONTENT"
```

## 四个核心操作

### 操作1: 库存查询
**触发词**: "冰箱里有什么"、"还有X吗"、"B层有什么"

**流程**:
1. 读取笔记，解析表格
2. 根据用户问题返回对应信息
3. 如果问某个具体物品，搜索所有层找到它
4. 如果问某一层，返回该层的完整列表
5. 如果问全部，返回三层汇总

**输出格式**: 用简洁的自然语言回答，例如：
- "B层有：鸡蛋6个、牛奶1盒（2/10过期）"
- "有的，A层冷冻区有2袋饺子"
- "没有找到番茄，可能用完了"

### 操作2: 库存更新（增加/修改）
**触发词**: "买了X"、"放了X进冰箱"、"加了X"

**流程**:
1. 读取笔记，解析表格
2. 识别用户提到的物品、数量、层级
3. 如果用户没说放哪层，**主动询问**
4. 如果物品已存在于该层，更新数量（累加或替换，根据语境判断）
5. 如果是新物品，在对应层的表格中新增一行
6. 重建完整 HTML 并写回

**重要**: 更新时必须保留笔记的完整结构（所有三个表格 + 餐食记录），只修改目标表格的内容。

### 操作3: 消耗记录（做饭 + 扣减库存）
**触发词**: "今天做了X"、"午餐是X"、"用了X个鸡蛋"

**流程**:
1. 读取笔记，解析表格和餐食记录
2. 在餐食记录区域添加今日记录：
   - 如果今天的日期条目已存在，在该日期下追加
   - 如果不存在，在餐食记录区域最上方创建新日期条目
3. 如果用户提到了具体用掉的食材和数量，自动扣减库存表格中对应物品的数量
4. 如果扣减后数量为0，从表格中移除该行
5. 重建完整 HTML 并写回

**输出格式**:
- "已记录：2025-02-06 午餐 番茄炒蛋。库存已更新：鸡蛋 6→4个，番茄 3→2个"

### 操作4: 历史查看
**触发词**: "这周做了什么饭"、"最近吃了什么"、"餐食记录"

**流程**:
1. 读取笔记，解析餐食记录区域
2. 根据用户的时间范围筛选记录
3. 以清晰的格式返回

## HTML 构建规则

当重建笔记 HTML 时，严格使用以下结构：

```html
<h1>🧊 冰箱库存</h1>

<h2>A层（冷藏）</h2>
<table border="1" style="border-collapse: collapse; width: 100%;">
<tr style="background:#f0f0f0;"><th>物品</th><th>数量</th><th>备注</th></tr>
<tr><td>物品名</td><td>数量</td><td>备注</td></tr>
</table>

<h2>B层（化冻区）</h2>
<table border="1" style="border-collapse: collapse; width: 100%;">
<tr style="background:#f0f0f0;"><th>物品</th><th>数量</th><th>备注</th></tr>
<tr><td>物品名</td><td>数量</td><td>备注</td></tr>
</table>

<h2>C层（冷冻区）</h2>
<table border="1" style="border-collapse: collapse; width: 100%;">
<tr style="background:#f0f0f0;"><th>物品</th><th>数量</th><th>备注</th></tr>
<tr><td>物品名</td><td>数量</td><td>备注</td></tr>
</table>

<hr>

<h1>📅 餐食记录</h1>

<h3>2025-02-06</h3>
<ul>
<li>午餐：番茄炒蛋</li>
<li>晚餐：饺子</li>
</ul>

<h3>2025-02-05</h3>
<ul>
<li>午餐：炒青菜</li>
</ul>
```

**关键规则**:
- 表格如果没有数据行（只有表头），保留表格结构但不添加空行
- 餐食记录按日期倒序排列（最新在上）
- 每次写回时重建完整 HTML，确保结构一致性

## 交互原则

1. **自然语言优先**: 用户不需要记忆任何格式，直接用口语表达
2. **智能推断**: 如果用户说"牛奶喝完了"，理解为将牛奶数量清零并移除
3. **主动确认**: 操作完成后简洁确认结果，如"已更新：鸡蛋从6个减为4个"
4. **缺失信息时询问**: 如果不确定放哪层或具体数量，直接问用户
5. **容错**: 如果找不到笔记，提示用户可能需要先创建
