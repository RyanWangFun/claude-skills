## 视频标题

### 核心目标

视频标题的唯一使命：**在信息流中抓住注意力，让用户点击。**

用户决定是否点击的时间只有2-3秒，标题必须在这个时间内完成：
1. 传达核心价值（我能得到什么）
2. 制造好奇心（为什么要看）
3. 建立相关性（这跟我有关）

### 标准要求

**字数**：15-25字为宜
- 太短：信息量不足，难以吸引
- 太长：信息流中被截断，重点不突出

**必备元素**：
- 明确的价值承诺 或 情绪钩子
- 与内容高度匹配（避免标题党反噬）

### 六种标题结构

#### 1. 数字+价值型

用具体数字量化价值，降低阅读决策成本。

```
模板：「N个/种/步 + 具体价值」

示例：
- 「3个技巧让你的视频播放量翻倍」
- 「5分钟学会用AI写出爆款标题」
- 「我用这1个方法，3个月涨粉10万」
```

**适用场景**：教程、方法论、工具推荐

#### 2. 痛点+方案型

先戳痛点引发共鸣，再给出解决方案。

```
模板：「痛点描述 + 解决方案」

示例：
- 「还在为写不出标题发愁？这个公式一学就会」
- 「剪辑效率太低？试试这个被低估的功能」
- 「涨粉遇到瓶颈怎么办？分享我的破局方法」
```

**适用场景**：问题解决、经验分享

#### 3. 反常识型

打破固有认知，制造认知冲突。

```
模板：「反直觉观点 + 原因暗示」

示例：
- 「为什么努力更新反而掉粉？」
- 「花钱买流量是最蠢的做法」
- 「我不再追热点后，播放量反而更高了」
```

**适用场景**：观点输出、经验总结、深度分析

#### 4. 身份认同型

用身份标签筛选目标受众。

```
模板：「身份群体 + 专属价值」

示例：
- 「高手都在用的剪辑技巧」
- 「职场人必看的AI工具清单」
- 「设计师绝对不能错过的配色网站」
```

**适用场景**：垂直领域、专业内容

#### 5. 时效性型

用时间标签制造紧迫感。

```
模板：「时间限定 + 价值内容」

示例：
- 「2025年最值得学的10个AI工具」
- 「这个月必看的5部高分电影」
- 「最新！Claude又更新了这些功能」
```

**适用场景**：盘点、更新、趋势

#### 6. 故事悬念型

用故事开头制造悬念。

```
模板：「戏剧性事件 + 悬念」

示例：
- 「我因为这个视频被骂了3天」
- 「做了5年自媒体，我决定停更」
- 「客户看完我的方案后沉默了」
```

**适用场景**：经历分享、复盘、情感内容

### 执行流程

1. **理解内容核心**：这个视频的一句话卖点是什么？
2. **确定目标受众**：谁会对这个内容感兴趣？
3. **选择标题策略**：根据内容类型选择合适的结构
4. **生成3-5个选项**：每个选项用不同策略
5. **标注策略类型**：方便用户理解每个标题的设计意图

## 文章标题

### 核心目标

文章标题的目标与视频标题不同：**准确传达主旨，吸引目标读者。**

文章读者的决策时间相对更长，标题可以：
- 更注重信息传达而非吸引眼球
- 体现文章的核心洞察或价值
- 与个人风格保持一致

### 标准要求

**字数**：灵活，通常10-30字
- 公众号：建议15-25字，太长会被截断
- 博客：可以更长，甚至使用副标题
- 社区：简洁为主

**核心原则**：
- 与内容高度匹配
- 体现核心价值或洞察
- 符合个人写作风格

### 五种标题结构

#### 1. 主题陈述型

直接点明文章主题，简洁明了。

```
模板：「关于XX的思考」「XX的几点观察」

示例：
- 「关于AI写作的一些思考」
- 「自媒体创作的几点观察」
- 「产品思维在日常生活中的应用」
```

**适用场景**：观点输出、思考总结

#### 2. 观点先行型

把核心观点放在标题里。

```
模板：「XX其实是YY」「XX的本质是YY」

示例：
- 「写作其实是思考的外化」
- 「所有的焦虑本质上都是能力不足」
- 「AI不会取代人，只会改变生产方式」
```

**适用场景**：深度分析、观点表达

#### 3. 问题引导型

用问题引发读者思考。

```
模板：「如何理解XX？」「为什么XX？」

示例：
- 「如何建立自己的写作风格？」
- 「为什么说风格比内容更重要？」
- 「什么样的内容值得长期投入？」
```

**适用场景**：方法论、深度探讨

#### 4. 方法论型

强调实用价值。

```
模板：「XX的N种方法」「XX指南」

示例：
- 「AI写作指南3.0：编程式写作」
- 「提升写作效率的5个习惯」
- 「从零开始的个人品牌搭建指南」
```

**适用场景**：教程、方法论

#### 5. 故事引入型

用故事或场景引入。

```
模板：「从XX说起」「那一年/次/天...」

示例：
- 「从一次失败的投稿说起」
- 「我是如何从程序员转型做自媒体的」
- 「那些年我踩过的内容创作坑」
```

**适用场景**：经验分享、成长故事

## 视频简介

### 核心目标

简介是标题的补充，目的是：
1. 提供标题未能传达的信息
2. 强化观看动机
3. 引导用户行动（点赞、关注、评论）

### 结构模板

```
[钩子句] - 1句话抓住注意力，与标题呼应但不重复
[内容概要] - 2-3句说明核心内容
[价值承诺] - 看完能获得什么
[行动号召] - 可选，引导互动
```

### 字数建议

| 类型 | 字数 | 特点 |
|-----|-----|-----|
| 短视频（<3分钟） | 50-150字 | 精炼，重点突出 |
| 中视频（3-15分钟） | 100-200字 | 可加时间戳 |
| 长视频（>15分钟） | 150-300字 | 时间戳必备 |

### 示例

**短视频简介示例**：
```
用AI写文章，最怕的就是「AI味」太重。

这个视频分享我的解决方案：编程式写作法。核心就8个字：先写提纲，再写全文。

看完你会知道：
- 如何让AI产出符合你个人风格的内容
- 模块化写作的具体操作流程
- 为什么说「风格比内容更重要」

#AI写作 #内容创作 #自媒体
```

**长视频简介示例**：
```
做了半年自媒体，我总结出一套可复用的内容创作流程。

这个视频是完整的方法论分享，从选题到发布，每一步都有可执行的方法。

内容大纲：
00:00 开场：为什么要系统化创作流程
02:30 选题：如何找到值得写的话题
08:15 结构：三种万能的内容框架
15:40 写作：模块化写作的具体操作
23:00 发布：不同平台的适配策略
28:30 总结：创作流程的核心原则

如果你也在做内容创作，希望这个视频能帮到你。
欢迎在评论区分享你的创作心得！

#内容创作 #自媒体运营 #创作方法论
```

## 标题优化技巧

### 自检清单

写完标题后，用这些问题自检：

- [ ] 2秒内能看懂核心信息吗？
- [ ] 目标受众会觉得「跟我有关」吗？
- [ ] 有没有制造足够的好奇心或价值感？
- [ ] 与内容是否高度匹配？（避免标题党）
- [ ] 字数是否在合适范围内？

### 常见问题

**问题1：太抽象**
```
❌ 「关于创作的思考」
✅ 「写了100篇文章后，我对创作的3点新认知」
```

**问题2：信息量不足**
```
❌ 「AI很有用」
✅ 「AI帮我把写作效率提升了3倍」
```

**问题3：过度标题党**
```
❌ 「震惊！这个方法让我月入百万」
✅ 「我用这个方法，半年涨粉5万」
```

**问题4：与内容不符**
```
❌ 标题说「3个技巧」，内容讲了7个
✅ 标题与内容结构严格对应
```

### A/B测试思路

如果不确定哪个标题更好，可以：
1. 准备2-3个候选标题
2. 在不同平台/时间测试
3. 观察点击率和完播率数据
4. 积累自己的标题数据库
