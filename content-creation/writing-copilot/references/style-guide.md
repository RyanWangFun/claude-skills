## 风格分析框架

将写作风格拆解为6个可观测维度：

### 1. 语言层面

**用词偏好**
- 口语化 vs 书面化
- 简洁 vs 丰富
- 专业术语密度
- 常用修饰词类型（形容词、副词）

**句式特征**
- 平均句长（短句/长句偏好）
- 复杂句比例
- 常用句式模式
- 排比、对仗等修辞手法

**标点使用**
- 感叹号、问号的使用频率
- 破折号、省略号的偏好
- 段落内标点密度

### 2. 结构层面

**篇章组织**
- 总分 / 分总 / 总分总
- 递进式 / 并列式
- 章节层级深度（1-4级标题使用）

**段落特征**
- 平均段落长度
- 单句成段习惯
- 段落间过渡方式（直接并列 / 过渡句）

**信息密度**
- 核心观点的呈现方式（开门见山 / 层层铺垫）
- 例证比例（多案例 / 少案例）
- 留白程度（紧凑 / 舒缓）

### 3. 叙述层面

**视角选择**
- 第一人称 / 第二人称 / 第三人称
- 是否直接对话读者（"你" / "我们" / 客观陈述）

**节奏控制**
- 快节奏（直奔主题）vs 慢节奏（铺垫引入）
- 张弛节奏变化
- 高潮设置方式

**情感基调**
- 客观理性 / 感性温暖
- 激昂 / 平和
- 幽默 / 严肃

### 4. 修辞层面

**常用修辞手法**
- 比喻、拟人
- 排比、对偶
- 设问、反问
- 引用、典故

**表达策略**
- 直接陈述 / 间接暗示
- 正面论证 / 反面对比
- 具体案例 / 抽象概念

### 5. 内容层面

**选材偏好**
- 案例类型（个人经历 / 新闻事件 / 研究数据）
- 引用来源（学术 / 大众 / 自创）
- 论据丰富度

**论证方式**
- 逻辑推理 / 感性共鸣
- 数据支撑 / 经验分享
- 权威引用 / 个人洞察

### 6. 格式层面

**排版习惯**
- Markdown 元素使用（列表、引用块、代码块）
- 强调方式（加粗、斜体、下划线）
- 图片、表格使用频率

**视觉设计**
- 留白和分段
- Emoji 使用倾向
- 特殊符号偏好

## 风格学习流程

### 步骤1：收集样本

**样本要求**
- 至少3篇同类型文章
- 总字数建议 > 5000字
- 最好是近期创作（风格稳定）

**收集方式**
- 用户直接提供参考文章
- 从指定目录读取历史文章
- 从用户当前项目中检索相关文档

### 步骤2：多维度标注

对每篇样本进行6维度分析，记录：

```
文章：[标题]
- 语言层面：[口语化/书面化]，[平均句长]，[常用词汇特征]
- 结构层面：[组织方式]，[段落特征]
- 叙述层面：[视角]，[节奏]，[基调]
- 修辞层面：[常用手法]
- 内容层面：[选材偏好]，[论证方式]
- 格式层面：[Markdown使用]，[排版特点]
```

### 步骤3：提取共性特征

从多篇样本中识别**稳定重复**的特征：

**高频特征**（出现在所有样本中）
- 这些是风格的"核心基因"
- 必须在新创作中保持

**中频特征**（出现在部分样本中）
- 这些是风格的"可选特征"
- 根据具体场景灵活使用

**低频特征**（偶尔出现）
- 可能是特定主题的特殊处理
- 不强制复现

### 步骤4：形成风格画像

将提取的特征整合为结构化的风格画像：

```markdown
## 风格画像：[用户名]

### 核心特征（必须保持）
1. 用词：[特征描述]
2. 句式：[特征描述]
3. 结构：[特征描述]
4. 叙述：[特征描述]

### 典型案例
- 开头方式：[示例]
- 论证方式：[示例]
- 结尾方式：[示例]

### 禁忌清单
- 避免：[不符合风格的表达方式]
- 不用：[不符合的句式或词汇]
```

### 步骤5：验证与调整

**验证方法**
- 生成测试段落，请用户确认风格匹配度
- 对比生成文本与原文的6维度特征
- 根据用户反馈微调风格画像

## 风格特征提取

### 语言特征提取技巧

**识别标志性用词**
```
步骤：
1. 统计高频词汇（排除虚词）
2. 识别独特表达（与通用写作的差异）
3. 提取口头禅、习惯用语
```

**示例**：
- 用户A：频繁使用"其实"、"说白了"、"简单来说" → 偏好口语化过渡
- 用户B：频繁使用"本质上"、"从根本上"、"核心在于" → 偏好深度分析

**分析句式模式**
```
步骤：
1. 计算平均句长
2. 统计问句、感叹句比例
3. 识别常用句式模板
```

**示例**：
- "这是一个...的时代" → 时代定义句式
- "为什么...？因为..." → 自问自答句式
- "不是...而是..." → 对比辨析句式

### 结构特征提取技巧

**识别组织模式**
```
步骤：
1. 标注各文章的结构类型
2. 统计标题层级使用习惯
3. 分析段落长度分布
```

**常见模式**：
- 金字塔结构：核心观点前置，层层支撑
- 故事化结构：场景引入 → 问题 → 解决方案
- 列表结构：多个并列要点逐一展开

### 叙述特征提取技巧

**识别叙述视角**
```
分析要点：
- 人称使用频率（我/你/他）
- 是否直接与读者对话
- 客观陈述 vs 主观评价的比例
```

**识别情感基调**
```
观察指标：
- 情感词汇密度
- 感叹号等标点的使用
- 价值判断的表达方式
```

## 风格复现技巧

### 宏观复现策略

**结构层面**
- 采用用户惯用的篇章组织方式
- 匹配段落长度和分段习惯
- 保持信息密度一致

**叙述层面**
- 使用相同的人称视角
- 保持相似的节奏和基调
- 复现引入和过渡的方式

### 微观复现策略

**用词层面**
- 优先使用用户的高频词汇
- 保持口语化/书面化程度一致
- 复现标志性表达和口头禅

**句式层面**
- 控制句长在用户惯用范围
- 使用用户偏好的句式模式
- 保持标点使用习惯

### 复现质量检验

**自查清单**
- [ ] 用词风格是否匹配（口语化程度）
- [ ] 句式长度是否在惯用范围
- [ ] 段落组织是否符合习惯
- [ ] 叙述视角是否一致
- [ ] 情感基调是否吻合
- [ ] 修辞手法是否自然融入
- [ ] 整体阅读感受是否相似

**对比验证**
将生成文本与参考文章并列对比：
- 挑选3-5个段落进行特征对比
- 识别差异较大的部分
- 针对性调整直至匹配

## 常见风格类型

### 1. 融贯散文式

**核心特征**
- 思想流畅展开，如散文般连贯
- 追求洞察深度和语言优雅
- 避免机械化的列表和框架
- 注重完整性和精炼性

**适用场景**
- 深度思考类文章
- 个人感悟和洞察
- 理论探讨和哲学思辨

**典型示例**
> "我们的沟通，是思想的自然流动。其核心在于洞察本质，力求用优雅简洁的语言，完整而精粹地呈现一个想法。"

### 2. 实用直接式

**核心特征**
- 开门见山，直奔主题
- 结构清晰，要点明确
- 重视可操作性和实用价值
- 大量使用列表和步骤

**适用场景**
- 教程和操作指南
- 技术文档
- 问题解决方案

**典型示例**
> "具体步骤如下：1. 首先...... 2. 然后...... 3. 最后......  这样你就能快速完成任务。"

### 3. 对话互动式

**核心特征**
- 大量使用"你"、"我们"等第二人称
- 设问、反问引导读者思考
- 语气亲切，如面对面交流
- 适度使用口语化表达

**适用场景**
- 知识分享类文章
- 个人成长建议
- 产品介绍和推广

**典型示例**
> "你有没有遇到过这种情况？我想大家都经历过。那么，我们该如何应对呢？"

### 4. 数据论证式

**核心特征**
- 大量引用数据、研究、案例
- 逻辑严密，论证充分
- 客观中立，避免主观判断
- 结构化强，常用图表

**适用场景**
- 研究报告
- 行业分析
- 专业评论

**典型示例**
> "根据XXX研究显示，有73%的用户......这一数据表明......"

### 5. 故事叙述式

**核心特征**
- 以故事或场景引入
- 情节化呈现观点
- 注重代入感和情感共鸣
- 善用细节描写

**适用场景**
- 品牌故事
- 案例分享
- 经验总结

**典型示例**
> "2019年的一个冬天，我遇到了一个困扰许久的问题......这次经历让我深刻理解了......"

### 6. 清单框架式

**核心特征**
- 高度结构化
- 多级标题和列表
- 信息密集，易于检索
- 强调完整性和系统性

**适用场景**
- 知识整理
- 方法论总结
- 工具使用指南

**典型示例**
> "本文包含5个部分：一、概念解析 二、核心方法 三、实践案例 四、常见问题 五、总结建议"

## 风格适配建议

### 单一风格保持

当用户有明确的个人风格时：
- 严格遵循用户的风格画像
- 不擅自"优化"或"改进"风格
- 保持标志性表达不变

### 风格灵活切换

当需要针对不同场景调整风格时：
- 明确不同场景的风格要求
- 保持核心特征，调整外围特征
- 提供多个风格版本供选择

### 风格融合创新

当需要创造新风格时：
- 提取多个参考风格的优点
- 确保融合后的一致性
- 验证新风格的可读性和适用性

---

## 特殊注意事项

**避免过度拟合**
- 不要机械复制每个细节
- 保持自然和可读性优先
- 风格是服务于内容的，不是目的

**尊重个人特色**
- 某些"不完美"可能正是个人特色
- 不随意纠正用户的习惯表达
- 保留一定的个性化"毛刺"

**风格与场景匹配**
- 不同平台可能需要不同风格
- 公众号 vs 技术博客 vs 社交媒体
- 根据受众调整风格强度
