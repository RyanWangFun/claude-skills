# 文章重构方法论

本文档提供完整的文章重构框架，用于优化现有文章的结构、风格和表达。

## 核心工作流程（5步法）

### 第1步：需求澄清与维度拆解

接收到重构需求后，立即将其拆解为独立维度：

**结构维度**
- 章节组织：是否可以调整标题、段落顺序
- 逻辑框架：论证链条、信息层级
- 信息密度：详略得当、重点突出

**风格维度**
- 语言表达：用词、句式、修辞手法
- 叙述节奏：紧凑 vs 舒缓、直接 vs 委婉
- 语气基调：正式/轻松、客观/主观

**内容维度**
- 核心观点：主旨、论点、结论
- 支撑材料：案例、数据、引用
- 专业术语：保留程度、解释方式

**形式维度**
- 标题优化：吸引力、准确性
- 格式规范：Markdown、段落间距
- 长度控制：扩写或压缩

**标准提问模板**：
```
"我来帮你明确这个重构需求，请确认：

1. 结构调整权限：标题/章节/段落组织是否可以调整？
2. 内容保真要求：哪些内容必须保持不变？（专业术语、案例、数据等）
3. 风格偏好：希望保持原风格还是尝试新风格？可以先看多个版本对比选择。"
```

### 第2步：原文深度理解

完整阅读原文，系统性把握：

**内容层面**
- 核心论点和论证逻辑
- 关键信息点（案例、数据、引用）
- 信息完整性和准确性

**结构层面**
- 现有章节组织逻辑
- 段落间的过渡和衔接
- 结构的优缺点诊断

**风格层面**
- 整体语言特色
- 句式和用词偏好
- 修辞手法运用

### 第3步：多方案呈现

基于需求提供2-3个差异化版本：

**版本设计原则**
- 每个版本在某个维度上有明显特色
- 清晰标注各版本的核心差异
- 便于用户快速对比和判断

**典型版本组合**
- 版本A：结构优化型（逻辑更清晰，章节重组）
- 版本B：风格保真型（保持原有风格，仅优化表达）
- 版本C：创新探索型（尝试新风格或新结构）

**版本呈现格式**：
```
已提供 [N] 个版本：
- 版本1：[核心特点] - 适合[使用场景]
- 版本2：[核心特点] - 适合[使用场景]

你可以：
1. 直接选择某个版本
2. 混合不同版本的优点（如'版本1的结构+版本2的风格'）
3. 在某个版本基础上提出调整建议
```

### 第4步：灵活组合执行

根据用户反馈，允许跨版本混合：

**组合策略**
- 识别用户对各维度的偏好
- 提取不同版本的优点
- 有机整合成最优方案

**常见组合模式**
- "用A的结构 + B的风格"
- "用A的标题 + B的内容组织 + C的语言风格"
- "在B基础上，采用A的开头和结尾"

### 第5步：保存与交付

**默认行为**
- 保存为新文件，保留原文
- 命名规则：`原文件名_重构版.md` 或用户指定名称

**交付说明**
用3-5个要点说明重构内容：
- 调整了哪些维度
- 做了哪些核心改动
- 保留了哪些原有特征

## 关键决策矩阵

不同风险偏好对应的重构策略：

| 维度 | 保守方案 | 平衡方案 | 激进方案 |
|------|---------|---------|---------|
| **结构** | 保持原有章节 | 微调顺序和层级 | 重新设计逻辑框架 |
| **风格** | 仅修正语病 | 优化表达但保持基调 | 彻底改写风格 |
| **内容** | 一字不改 | 删减冗余/补充细节 | 重新组织论证 |
| **标题** | 保持原标题 | 微调表述 | 创作新标题 |

## 执行原则

1. **先理解，后动手**：永远先读完原文再提供方案
2. **拆解维度，独立处理**：结构/风格/内容应该能独立调整和组合
3. **提供选择，而非决策**：给用户看到不同可能性，让他们选择
4. **保留原文**：重构结果默认保存为新文件
5. **简洁说明**：交付时用3-5个要点说明改动内容

## 质量检查清单

重构完成后，逐项检查：

- [ ] 核心观点和论证逻辑是否保持完整？
- [ ] 专业术语和关键信息是否准确无误？
- [ ] 文章的流畅性是否明显提升？
- [ ] 是否符合用户在各维度上的明确要求？
- [ ] 引用、截图等格式元素是否保留正确？
- [ ] 段落间的过渡是否自然连贯？
- [ ] 是否消除了重复和冗余？
- [ ] 标题是否准确反映内容？

## 常见场景快速指南

### 场景1：纯风格优化
- 重点：第2步深度理解风格 + 第3步提供多风格版本
- 保持：结构、内容、核心论点完全不变
- 优化：句式、用词、表达方式

### 场景2：结构重组
- 重点：第2步诊断结构问题 + 第3步提供多结构方案
- 保持：内容完整性、风格基调
- 优化：章节顺序、逻辑层级、信息密度

### 场景3：全面提升
- 重点：所有5步完整执行
- 优化：结构、风格、内容全方位
- 注意：保持核心观点不变，确保用户认可

### 场景4：标题优化
- 重点：理解文章核心 + 提供3-5个标题选项
- 考虑：吸引力、准确性、SEO、平台特点
- 类型：疑问式、数字式、利益式、情感式

## 特殊注意事项

**风格混合的技巧**
- 骨架来自结构优秀的版本
- 血肉来自风格优秀的版本
- 确保两者融合自然，不产生违和感

**保持原有特色**
- 用户的口头禅、标志性表达要保留
- 特定领域的专业术语不随意替换
- 个人风格的"不完美"可能正是特色

**避免过度优化**
- 不是所有地方都需要"更好"
- 有时"不够完美"的表达更真实
- 保持适度的个性化和口语化
