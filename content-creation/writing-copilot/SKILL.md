## 一、标题创作

标题分两类，各有不同标准。

### 视频标题

**核心目标**：在信息流中抓住注意力，3秒内传达价值

**标准要求**：
- 字数：15-25字为宜
- 必须有明确的价值承诺或情绪钩子
- 避免标题党但要有吸引力

**常用结构**：
```
1. 数字+价值：「3个技巧让你的XX提升50%」
2. 痛点+方案：「还在为XX烦恼？这个方法彻底解决」
3. 反常识：「为什么XX反而更有效？」
4. 身份认同：「高手都在用的XX方法」
5. 时效性：「2025年最值得学的XX」
```

**执行流程**：
1. 理解视频核心内容和目标受众
2. 提供3-5个不同风格的标题选项
3. 标注每个标题的策略（数字型/痛点型/反常识型等）
4. 让用户选择或混合

### 文章标题

**核心目标**：准确传达文章主旨，吸引目标读者

**标准要求**：
- 字数：灵活，但通常10-30字
- 与内容高度匹配，不做标题党
- 体现文章的核心价值或洞察

**常用结构**：
```
1. 主题陈述：「关于XX的一些思考」
2. 观点先行：「XX其实是YY」
3. 问题引导：「如何理解XX？」
4. 方法论：「XX的N种方法」
5. 故事引入：「从XX说起」
```

**详细指南**：见 `references/title-guide.md`

## 二、简介/描述创作

主要用于视频描述和内容概要。

**核心目标**：补充标题信息，引导用户行动

**结构模板**：
```
[钩子句] - 吸引继续阅读
[内容概要] - 2-3句说明核心内容
[价值承诺] - 看完能获得什么
[行动号召] - 可选，引导互动
```

**字数建议**：
- 短视频描述：50-150字
- 长视频描述：150-300字
- 可包含时间戳（长视频）

**执行流程**：
1. 理解视频/内容的核心价值
2. 写出钩子句（与标题呼应但不重复）
3. 提炼2-3个核心看点
4. 可选：添加行动号召或互动引导

## 三、短文创作

用于社交平台的文本分享（小红书、即刻、Twitter等）。

**核心原则**：一个短文 = 一个清晰的观点/信息/情绪

### 通用标准

**内容要求**：
- 一篇短文只传达一个核心信息
- 开头即高潮，不要铺垫
- 口语化、有个人温度
- 适度使用表情符号增加可读性

**结构模式**：
```
A. 观点型：观点 → 论据/例子 → 金句收尾
B. 故事型：场景 → 转折 → 感悟
C. 清单型：引入 → 要点1/2/3 → 总结
D. 对话型：问题 → 回答 → 延伸
```

### 平台适配提示

虽然核心方法论统一，但不同平台有微调：

| 平台 | 字数 | 调性 | 特殊要求 |
|-----|-----|-----|---------|
| 小红书 | 300-800字 | 亲切、实用、有代入感 | 段落短，多空行，emoji点缀 |
| 即刻 | 50-500字 | 真诚、有洞察、圈子感 | 可以更随性，像发朋友圈 |
| Twitter/X | <280字（中文约140字） | 精炼、有态度 | 一句话能说清就不用两句 |

**详细指南**：见 `references/short-form-guide.md`

## 四、长文创作

深度内容创作，**核心要求：去除AI味，保持个人风格。**

### 核心原则：编程式写作

基于「AI写作指南3.0」的方法论：

```
人提供原创输入 → AI结构化执行 → 模块化写作 → 风格一致性
```

**去AI味的关键**：
1. **原创输入充足**：用户提供口述转录、笔记、想法，越多越好
2. **模块化写作**：先提纲，再分段（每次200-400字），不要一次性生成
3. **风格参考明确**：提供2-3篇风格参考文章，只学文风不学内容
4. **上下文精简**：只放绝对必要的文件，越少越好

### 工作流程

**第一步：准备阶段**

询问用户：
```
"开始长文创作前，我需要了解：

1. 主题：你想写什么？核心观点是什么？
2. 原创素材：你有哪些原始材料？（口述转录/笔记/想法）
3. 风格参考：有没有你过往写得好的文章？（2-3篇即可）
4. 目标读者：谁会读这篇文章？
5. 预期长度：大概多少字？"
```

**第二步：读取资料，撰写提纲**

- 仔细阅读原创素材，提取核心观点
- 学习风格参考的表达方式（只学风格，不学内容）
- 生成2-3个提纲方案，让用户选择

**第三步：模块化写作**

- 提纲确认后，逐段写作
- 每次写200-400字
- 写完一段，征求反馈后再继续
- 保持风格一致性

**第四步：整体润色**

- 检查论述连贯性
- 确保风格统一
- 校对标点符号

### 文风要求

- **标点符号**：全部使用中文标点
- **引号**：使用「」而非""
- **论述风格**：自然流畅，有具体案例和细节
- **禁止**：空洞的大路货、模板化表达

### 质量标准

✅ 读者能一眼看出这是用户写的（风格明确）
✅ 论述充分自然，有具体案例和细节
✅ 标点符号全部正确
✅ 结构清晰，过渡自然

**详细指南**：见 `references/long-form-guide.md`

## 五、Tag/标签生成

通用能力，服务于所有内容形式。

### 核心原则

Tag的目的是**被发现**和**被归类**：
- 帮助内容在平台上被搜索到
- 帮助建立内容之间的关联
- 体现内容的核心主题

### 生成策略

```
1. 核心主题Tag：内容的主要领域（如 #AI写作 #个人成长）
2. 具体话题Tag：内容涉及的具体话题（如 #Claude #提示词）
3. 受众Tag：目标读者可能搜索的词（如 #效率工具 #自媒体运营）
4. 情绪/风格Tag：可选，体现内容调性（如 #干货 #深度思考）
```

### 执行流程

1. 理解内容的核心主题和目标受众
2. 生成3-5个核心Tag + 3-5个扩展Tag
3. 按平台特性调整格式：
   - 小红书：#话题标签#（平台格式）
   - 即刻：#话题#
   - Twitter：#Hashtag（英文为主）
   - 公众号/博客：可作为分类标签

### 注意事项

- Tag数量适中，5-10个为宜
- 避免过于宽泛（如 #生活）或过于小众
- 核心Tag放前面，扩展Tag放后面

## 底层能力

以下能力作为支撑模块，可与上述形式创作组合使用。

### 风格学习与迁移

当用户说"用我的风格写"时调用。

**流程**：
1. 收集用户的风格参考文章（2-3篇）
2. 用6维度框架分析风格（语言/结构/叙述/修辞/内容/格式）
3. 提取核心特征，形成风格画像
4. 在创作时严格遵循风格画像

**详细指南**：见 `references/style-guide.md`

### 文章重构

当用户说"改写这篇文章"时调用。

**流程**：
1. 澄清重构需求（结构/风格/内容哪些可以调整）
2. 深度理解原文
3. 提供2-3个重构版本
4. 让用户选择或组合

**详细指南**：见 `references/rewrite-framework.md`

### 素材整理

当用户有散乱笔记需要整理成文章时调用。

**流程**：
1. 导入素材
2. 主题聚类
3. 观点提炼
4. 结构设计
5. 内容组织

**详细指南**：见 `references/workflow-templates.md`

## 通用原则

### 1. 始终先澄清需求
不假设用户意图，通过提问确认目标、受众、风格偏好。

### 2. 提供选择而非决策
给出2-3个选项，让用户选择或混合。

### 3. 模块化执行
复杂任务拆解为小步骤，每步完成后征求反馈。

### 4. 风格优先于内容
内容AI可以生产，但风格是稀缺的。始终确保产出符合用户的个人风格。

### 5. 上下文管理
只使用绝对必要的参考资料，避免信息污染。风格参考只学风格，不学内容。
