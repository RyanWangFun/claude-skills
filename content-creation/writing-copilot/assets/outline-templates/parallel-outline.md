# 并列式大纲模板

适用场景：介绍多个平行要点、方法或观点的文章

---

## 结构框架

```
引入 → 要点1 → 要点2 → 要点3 → 总结
```

---

## 详细大纲

### 一、引入

**目标**：引出主题，说明为什么重要
**内容**：
- [ ] 主题介绍
- [ ] 为什么需要了解这个主题
- [ ] 文章将覆盖的核心要点预告

**预计字数**：200-300字

---

### 二、核心要点1：[小标题]

**核心观点**：[用一句话概括]

**内容结构**：
- [ ] 观点阐述：[这个要点是什么]
- [ ] 原因/重要性：[为什么重要]
- [ ] 案例/数据支撑：[举例说明]
- [ ] 实践建议：[如何应用]

**预计字数**：400-600字

---

### 三、核心要点2：[小标题]

**核心观点**：[用一句话概括]

**内容结构**：
- [ ] 观点阐述：[这个要点是什么]
- [ ] 原因/重要性：[为什么重要]
- [ ] 案例/数据支撑：[举例说明]
- [ ] 实践建议：[如何应用]

**预计字数**：400-600字

---

### 四、核心要点3：[小标题]

**核心观点**：[用一句话概括]

**内容结构**：
- [ ] 观点阐述：[这个要点是什么]
- [ ] 原因/重要性：[为什么重要]
- [ ] 案例/数据支撑：[举例说明]
- [ ] 实践建议：[如何应用]

**预计字数**：400-600字

---

### 五、总结

**目标**：整合所有要点，强化核心价值
**内容**：
- [ ] 简要回顾三个要点
- [ ] 要点之间的关系（如何协同）
- [ ] 整体行动建议
- [ ] 结语

**预计字数**：200-300字

---

## 总计预计字数：1600-2400字

## 核心逻辑链

```
主题引入 → [要点1] + [要点2] + [要点3] → 整合总结
             ↓          ↓          ↓
          并列关系，同等重要
```

## 关键要点

- 三个要点应该是平行的，没有主次之分
- 每个要点结构保持一致（便于阅读）
- 要点之间可以有关联，但不是递进关系
- 总结时要整合所有要点，而非简单重复

## 变体

**3要点版**（推荐）：适合大部分场景
**5要点版**：适合内容丰富的主题，每个要点字数相应减少
**2要点版**：适合对比类主题（如"A vs B"）
