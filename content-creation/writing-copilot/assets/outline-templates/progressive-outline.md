# 递进式大纲模板

适用场景：需要层层深入分析问题的文章

---

## 结构框架

```
引入 → 现象 → 原因 → 方案 → 总结
```

---

## 详细大纲

### 一、引入（吸引注意）

**目标**：用引人入胜的方式引入主题
**内容**：
- [ ] 故事/场景/数据
- [ ] 提出核心问题
- [ ] 说明为什么重要

**预计字数**：200-300字

---

### 二、现象描述（是什么）

**目标**：让读者清晰理解现状
**内容**：
- [ ] 描述现象的具体表现
- [ ] 提供数据或案例支撑
- [ ] 指出值得关注的特点

**预计字数**：300-500字

---

### 三、原因分析（为什么）

**目标**：深入分析现象背后的原因
**内容**：
- [ ] 表层原因（显而易见的）
- [ ] 深层原因（本质性的）
- [ ] 因果关系梳理

**预计字数**：500-800字

---

### 四、解决方案（怎么办）

**目标**：提供可行的应对策略
**内容**：
- [ ] 方案A：[简要描述]
- [ ] 方案B：[简要描述]
- [ ] 方案C：[简要描述]
- [ ] 推荐方案及理由

**预计字数**：400-600字

---

### 五、总结升华（更深层思考）

**目标**：回归主题，提升立意
**内容**：
- [ ] 回顾核心观点
- [ ] 升华主题
- [ ] 行动呼吁

**预计字数**：200-300字

---

## 总计预计字数：1600-2500字

## 核心逻辑链

```
问题提出 → 现象观察 → 原因挖掘 → 方案设计 → 价值升华
```

## 关键要点

- 每层递进要有清晰的逻辑关系
- 从"是什么"到"为什么"再到"怎么办"
- 结尾要比开头站得更高
